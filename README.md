# Data Structure Lab

A collaborative lab implementing fundamental data structures in Python.

## Structures Implemented

| File | Structure | Description |
|------|-----------|-------------|
| `stack.py` | **Stack** | LIFO structure with push, pop, peek |
| `queue.py` | **Queue** | FIFO structure with enqueue, dequeue, front |
| `linked_list.py` | **Linked List** | Singly linked list with append, prepend, delete, search |
| `binary_search_tree.py` | **Binary Search Tree** | BST with insert, search, delete, inorder traversal |

## Running the Tests

```bash
pip install pytest
python -m pytest test_data_structures.py -v
```
